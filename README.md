# ArsLive

Независимая платформа для вебинаров Арсения: кабинет организатора, студия ведущего, приглашённый спикер и ассистент, чат и статистика. Светлая тема: тёплый белый, шампань, коричневый и шалфей.

Репозиторий: https://github.com/arsenchios/marketing

Это отдельная установка. Здесь нет действующих аккаунтов, записей, ключей, базы или подключений исходной платформы. Публикация кода в GitHub не подключает Railway, YouTube и Cloudflare автоматически.

## Локальный запуск

Нужны Node.js 24+, pnpm 11, FFmpeg/FFprobe и Poppler (`pdfinfo`). Для PowerPoint и OpenDocument нужен LibreOffice. Без LibreOffice остаются PDF и изображения.

```sh
./scripts/local.sh install
./scripts/local.sh dev
```

Открыть http://127.0.0.1:4350. В локальном режиме кнопка входа открывает тестовый кабинет без Google. Данные создаются в `.data/` и не попадают в Git. При необходимости скопировать `.env.example` в `.env` и заполнить свои параметры. Публичный режим требует настройки Google и PostgreSQL и не допускает локальный вход.

## Возможности

- Камера, микрофон, презентации до 400 слайдов / 100 МиБ, рисование и указатель; предварительная проверка связи и записи.
- Один главный ведущий и один приглашённый спикер с другого устройства. Приглашения спикера и ассистента отзывные; организатор управляет разрешениями.
- Доставка зрителям через YouTube либо собственный сервер с HLS, адаптация качества отправки и восстановление подключения.
- Чат, модерация, блокировки, ограничение частоты сообщений, заготовки и предложение зрителям.
- Отдельные кабинеты компаний, доступ администратора, статистика реального просмотра; тестовая активность настраивается отдельно.
- Запись на локальный диск сервера и, если настроено, в приватный R2. YouTube хранит свою запись отдельно. Для зрителя по ссылке комнаты повторный просмотр закрыт; небольшой хвост эфира доступен тем, кто смотрел его до завершения.
- Завершённый вебинар можно вернуть в ожидание, сохранив ссылку и записи отдельных запусков.

## Дизайн и имя

`shared/brand.ts` — название платформы, подпись, путь к логотипу и базовый акцент. SVG логотип и favicon находятся в `public/`. Тема — `src/arslive.css`, подключена последней. Логотип и оформление конкретного клиента задаются в его вебинаре. Анимация CSS не требует сторонних сервисов и учитывает настройку уменьшения движения.

Браузерные сценарии и границы проверок — [docs/TESTING.md](docs/TESTING.md). Запуск на новом сервере — [docs/RAILWAY_PLAN.md](docs/RAILWAY_PLAN.md). Архитектура и ограничения — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). Продолжение работы в новом чате — [docs/HANDOFF.md](docs/HANDOFF.md).

В текущей архитектуре один сервер обслуживает один активный эфир. Масштабирование числа одновременных эфиров требует выделения медиаворкеров; увеличение реплик само по себе не поддерживается.
