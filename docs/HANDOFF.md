# ArsLive — продолжение работы

Дата переноса: 22.10.2026. Новое имя по прямому выбору пользователя — **ArsLive**.

## Что это

Независимая копия платформы вебинаров в `arsenchios/marketing`. Локальная папка `marketing`, ветка `main`. Изначально репозиторий был пустым и публичным; пользователь планирует сделать его приватным самостоятельно. Не менять видимость без поручения.

Перенесён актуальный функциональный код, включая последние локальные исправления мобильного просмотра, обработки WebSocket, heartbeat, тайм-аута подключения и PDF.js. История Git, runtime, данные клиентов, секреты, старые брендовые изображения и приватные рабочие заметки не переносились. Исходная платформа не менялась.

## Что изменено

- Светлая визуальная система: молочный фон, шампань, коричневый, шалфей; кнопки, поля, карточки, модальные окна, чат, студия, кабинеты и комната зрителя.
- Новый SVG логотип и favicon, лёгкие CSS анимации с reduced-motion, центральный бренд `shared/brand.ts`.
- Свой namespace данных/cookies, схема PostgreSQL `arslive`, отдельный advisory lock; старые домены и ссылки заменены нейтральными примерами.
- Локальный порт 4350; отдельный client-preview 4351. Новый запуск требует отдельных Google OAuth / YouTube / PostgreSQL / volume / R2. Пока они не подключены.
- Документация написана заново для чистой установки. Настройка: RAILWAY_PLAN.md; устройство: ARCHITECTURE.md; проверки: TESTING.md.

## Сохранять при дальнейшей работе

Не возвращать старый брендинг, не обращаться к чужим production ресурсам и не смешивать данные. Не копировать .env. Не менять систему ролей, один основной media sender, ограничения архивов и изоляцию презентаций ради косметики. `src/arslive.css` импортируется последней. Название и пути логотипа меняются в `shared/brand.ts`; сам SVG, favicon и HTML title — статические ресурсы и обновляются при ребрендинге.

Перед работой прочитать AGENTS.md, README.md; проверить git status/diff/remote. Публикацию в GitHub, deployment и проверку реальных устройств фиксировать отдельно. Текущие ограничения: один одновременный эфир, постоянная сверка незавершённого YouTube после crash ещё не реализована. Не обещать, что локальный тест доказывает отсутствие проблем в любой сети.

## Проверки при переносе

TypeScript и build, 76 стандартных тестов пройдены. Локальный UI просмотр от 320 до 1440 пикселей без горизонтального переполнения. Chromium/WebKit UI smoke PASS. Полный синтетический PDF → HLS → MP4 PASS, включая безопасное завершение, возврат в ожидание, адаптацию качества, автоматическое продолжение у зрителя и возвращение ведущего через 65 секунд. Два спикера: камеры, mix-minus звук, mute/unmute, переподключение и итоговая MP4 PASS. Реальные YouTube/R2/TURN, Railway и физические устройства новой установки не подключались и не проверялись.
