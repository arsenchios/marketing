# Проверка ArsLive

Все команды запускать из корня репозитория. Использовать только отдельную локальную БД, синтетические данные и медиа. Не направлять тесты на клиентский или действующий эфир.

## Основные проверки

```sh
./scripts/local.sh install
./scripts/local.sh check
./scripts/local.sh test
./scripts/local.sh build
```

Тесты проверяют доступ компаний, приглашения, OAuth, CSRF/origin, жизненный цикл эфира, архив, презентации, WebSocket heartbeat и ошибки, переподключение, YouTube readiness и другие сценарии. PostgreSQL adapter проверяется отдельно; тесты не подключают внешнюю БД.

## Браузер и медиа

Нужны Playwright, Google Chrome, FFmpeg, FFprobe, Poppler. WebKit установить отдельно через Playwright, если отсутствует. Сначала собрать интерфейс. Для основных сценариев запустить чистый локальный сервер без .env, с новой DATA_DIR, например:

```sh
PORT=4355 APP_ORIGIN=http://127.0.0.1:4355 DATA_DIR=/tmp/arslive-smoke-fresh NODE_ENV=production ./scripts/local.sh dev
```

Не использовать этот каталог повторно для приёмки чистой установки. Проверить, что в окружении нет облачных ключей и APP_MODE=public. Затем в другом терминале:

```sh
TEST_ORIGIN=http://127.0.0.1:4355 node --import tsx tests/browser-smoke.mjs
TEST_ORIGIN=http://127.0.0.1:4355 node --import tsx tests/viewer-room-smoke.mjs
node --import tsx tests/two-speakers-smoke.mjs
```

`browser-smoke` — синтетические камера/звук, PDF, HLS, MP4, незавершённый запуск, безопасное завершение, переподключение через 65 секунд и снижение качества. `two-speakers-smoke` сам поднимает отдельный локальный сервер: приглашение, две камеры/голоса, общий canvas, mute/unmute и запись. `viewer-room-smoke` — Chromium/WebKit 320–1440, ожидание, живой чат, фиктивный YouTube SDK, HLS UI, длинные имена, прокрутка. Это UI-проверка, не реальный эфир YouTube.

Снимки и отчёты создаются в `test-results/`, исключённой из Git. Не публиковать оттуда пользовательские записи или локальные базы.

## Первичная приёмка нового бренда

Проверить вход, кабинет, редактор, студию, приглашения, настройки, статистику, комнату ожидания и эфир на светлом фоне. Достаточный контраст текста, видимый focus, отсутствие горизонтального скролла на 320/393/768/1440px. Анимация должна отключаться при `prefers-reduced-motion`. Пользовательские фотографии/видео/обложки не перекрашивать.

## Публичная установка

Пройти собственный Google OAuth, разрешения YouTube embedding, реальный TURN в разных сетях, R2 upload/download, iPhone Safari и desktop, восстановление из backup. Проверка сборки и локального медиапотока не подтверждает эти внешние подключения. Не проверять deployment автоматически, если пользователь будет принимать его сам.

Ограниченная нагрузочная утилита `scripts/load-viewers.mjs` требует явного `LOAD_TEST_ORIGIN`, той же комнаты в аргументе и отдельного разрешения на тест конкретного сервера. Она подключает максимум 50 зрителей на 3 минуты и потребляет сетевой трафик; при переносе не запускалась.
